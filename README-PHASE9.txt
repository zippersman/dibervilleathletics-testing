D'Iberville Athletics — Phase 9: Mobile Experience Upgrade

Changes:
- Added mobile.css as a shared responsive layer on all 20 HTML pages.
- Improved small-screen spacing, typography, card grids, controls, and touch targets.
- Made navigation horizontally scrollable on narrow screens, with fixed, viewport-bounded dropdown menus.
- Added safe-area handling for phones with display cutouts and home indicators.
- Made dense statistics tables horizontally scrollable rather than forcing page-wide overflow.
- Improved responsive behavior for common team, analytics, athlete, game, records, and milestone layouts.
- Added reduced-motion support and stronger visible keyboard focus.

No player data, team records, or Google Sheets sources were changed.

Validation: HTML parsing, local stylesheet references, JavaScript syntax, and ZIP integrity checked. Real-device/browser testing is still recommended for iOS Safari and Android Chrome, especially for navigation dropdown positioning and tables.
