HOW TO ACTIVATE CAREER TRACKING

Permanent IDs must come from the school.

  1. Add a column named Athlete ID to each team's published roster sheet.
  2. Assign each athlete a unique, permanent ID (for example, DHS-000123). Keep that ID when the athlete changes jersey number or moves between JV and varsity.
  3. Use the same ID in every season's archived records. Do not reuse IDs or assign them based only on matching names.
  4. For past seasons, add verified rows to career-archive.csv using the template included in this project.

The page currently reads the existing nine roster sheets and an optional archive CSV. If a sheet does not contain Athlete ID, its players remain visible in the source-coverage count but are not merged into a career profile.
